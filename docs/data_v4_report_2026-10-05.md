## 标点数据修复

v2 的 100 条标点候选仅 16 条通过；v3 加入正文一致、标点密度和切片首边界规则后，新的 100 条候选仍只有 11 条通过。进一步分析发现，引号不配对及首尾切片残缺是主要问题。

v4 增加以下确定性规则：

- 去除格式与标点后，输入和输出正文必须一致；
- 长文本有效标点密度不得低于 5%；
- 长文本必须包含句界标点；
- 中文双引号、单引号和直角引号必须按嵌套顺序成对；
- 切片开头不得无依据地增加句号、问号或叹号。

原始数据中有 46,078 条标点记录通过基础字段检查，v4 最终保留 3,513 条。各过滤原因采用互斥的首次命中统计：

| 原因 | 数量 |
|---|---:|
| 切片首边界异常 | 25,356 |
| 引号不配对或嵌套错误 | 15,132 |
| 标点密度不足 | 2,027 |
| 缺少句界标点 | 50 |
| 保留 | 3,513 |
